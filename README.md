# Bits

Small pieces of JavaScript.

Tiny, dependency-free utilities for the web.

## Bits

* [Dialog](docs/dialog.md) — native dialogs
* [Toast](docs/toast.md) — simple notifications
* [Drawer](docs/drawer.md) — slide-out panels
* [Countdown](docs/countdown.md) — countdown timer
* [drag](docs/drag.md) — drag and drop
* [loadImageFile](docs/loadImageFile.md) — load an image file
* [formatBytes](docs/formatBytes.md) — format file sizes

## Use

Import what you need:

```js
import { Dialog, Toast } from 'https://cdn.jsdelivr.net/gh/h6mzy/bits/js/index.js';
```

No framework.
No dependencies.
Just bits.
